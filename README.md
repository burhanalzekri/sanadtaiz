# منصة "سند تعز" — دليل المطور

## 🌟 نظرة عامة
"سند تعز" هي منصة يمنية للدعم النفسي الاجتماعي، تهدف إلى تقديم الدعم النفسي الأولي والتثقيف الصحي النفسي لأهل تعز واليمن، في ظل ظروف الحرب والنزوح. المنصة مجانية بالكامل، تحترم الخصوصية، وتعمل حتى بدون إنترنت.

## 🎯 الفئات المستهدفة
- النازحون.
- الأطفال والمراهقون.
- النساء.
- المصابون وذوو الإعاقة.
- الأسر المفقود عائلها.
- جميع من يعاني من ضغوط نفسية.

## ⚙️ التقنيات المستخدمة
- HTML5 / CSS3 / JavaScript (Vanilla): بدون أي مكتبات خارجية.
- PWA (Progressive Web App): لتعمل المنصة كتطبيق أندرويد وبدون إنترنت.
- LocalStorage: لحفظ تقدم المستخدم.
- GitHub Pages: لاستضافة المنصة مجاناً.

## 📂 هيكل الملفات الرئيسية
- index.html: لوحة التحكم الرئيسية.
- assets/style.css: التصميم الموحد.
- assets/app.js: البرمجة التفاعلية.
- manifest.json: إعدادات PWA.
- sw.js: Service Worker.

## 🚀 النشر (GitHub Pages)
1. رفع الملفات إلى GitHub.
2. تفعيل GitHub Pages من الإعدادات.
3. الرابط: https://\[username\].github.io/\[repo-name\]/

## 📱 تحويل المنصة إلى تطبيق APK
1. اذهب إلى PWABuilder.com.
2. ضع الرابط المباشر.
3. اختر Android > Download.
4. ثبت APK على هاتفك.
